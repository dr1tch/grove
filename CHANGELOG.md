# Changelog

All notable changes to Grove. Versions match the GitHub release tags. The apt package is named `folio`.

## 0.5.1 (2026-11-12)

### Added

- Markdown formatting toolbar in Edit and Split modes: headings, bold, italic, quotes, code, links, lists, tasks, undo and redo. Ctrl+B and Ctrl+I format the selection without changing the normal save and conflict handling.
- Insert from vault reuses existing images, PDFs, audio, video, drawings, and saved Mermaid blocks. Files can be embedded or linked; Mermaid source is copied without changing its original note. Vault-root references also work in new unsaved drafts.

### Fixed

- PDFs embedded in notes fill the note width at page proportions (up to 85% of the window height) instead of a fixed 430px box.
- `![[file.pdf]]`, `![[clip.mp4]]` and `![[song.mp3]]` embed the viewer or player instead of showing a broken image.

## 0.5.0 (2026-11-12)

### Added

- Sync a vault between computers through a private GitHub repository. Turn it on in Settings > Sync with "Create private repository" (needs the gh CLI) or "Use existing repository". Grove commits about 30 seconds after your last save, pulls when the vault opens, when the window gets focus and every 5 minutes, and pushes after each commit. Grove never stores a token; it uses your existing git, gh or SSH login.
- When two computers change the same lines, your version stays in place and the other one is saved beside it as `Note (conflict <device> <date>).md`. A banner offers "Compare side by side". A file deleted on one computer and edited on the other is kept.
- The sidebar footer shows the sync state: synced, syncing, offline, conflict or error. Offline changes are committed locally and pushed later.
- Files over 50 MB are not synced and are listed in Settings > Sync. `.folio/`, `.trash/` and export recovery copies are ignored.
- A folder that is already a git repository with uncommitted changes asks before its first commit. Sync never force-pushes or rewrites history, and turning it off leaves your files and git history as they are.

### Changed

- New note (Ctrl+N, Ctrl+T or the + button) opens an "Untitled" tab right away instead of asking for a file name in the sidebar. The first heading is the note's name. Nothing is written until you press Ctrl+S or close the tab; Grove then asks for the name and folder, with Save, Discard and Cancel. New drawings still ask for a name first. Closing Grove with an unsaved new note asks about it first.

## 0.4.7 (2026-11-12)

### Fixed

- Videos embedded in notes fill the note width at 16:9 instead of shrinking inside a fixed 430px box. Media fit now uses the frame's real padding, so tabs keep their margin and embeds use the full space.
- Embedded media show the real file size instead of 0.0 KB.

## 0.4.6 (2026-11-12)

### Fixed

- The video fullscreen button and F key work. Grove denied the browser's fullscreen permission along with every other permission; fullscreen is now allowed for the main window only. Escape leaves fullscreen.

### Changed

- Skip buttons show circular arrows with "10" instead of previous/next-track icons.
- Playback speed menu (0.5× to 2×) in the video and audio players; `<` and `>` step the speed.
- Play button and selected speed use a lighter accent so they stay readable on the black control bar.
- `scripts/video-controls-qa.mjs` clicks every control and key and fails if any does nothing.

## 0.4.5 (2026-11-11)

### Changed

- New video player modeled on player-glow-up: dark glass control bar with a seek bar (hover time, buffered range, thumb), 10-second skip, slide-out volume, time, zoom, fit and fullscreen. Controls hide after 3 seconds of playback. Click the video to play or pause. Keys: Space or K play, arrows ±5 s, J and L ±10 s, M mute, F fullscreen.
- New audio player card in the same style, with a large play button, seek bar, volume and animated level bars. Audio embedded in notes uses a compact frame.

### Fixed

- A cancelled drag on a video no longer toggles playback.
- Mermaid diagrams no longer show a light drop-shadow (a shiny edge in dark mode) under boxes.
- Wikilinks and embeds to files with spaces in their names (`[[My Note]]`, `![[My Drawing.excalidraw]]`) render as links and drawings instead of raw text.
- Scrolling a note no longer re-renders its diagrams, code blocks and embeds, which caused flicker and flashing scrollbars. `scripts/scroll-qa.mjs` guards this.

- Code previews keep lines aligned when line numbers change width (for example from 9 to 10).

### Added

- README logo and light and dark screenshots, generated by `scripts/readme-screenshot.mjs`.

## 0.4.0 (2026-11-11)

### Added

- Two independent document panes with one shared draft and save owner. Open beside, resize the divider and restore each pane's reading position.
- Named workspace presets per vault that save layout, tabs and folder expansion without copying note content.
- Drop files or paste screenshots into Markdown. External files are copied into the note's `attachments` folder without overwriting; vault files are linked. Images, PDF, video and audio preview inline. Undo removes links and keeps the files.
- Ctrl+K recent and fuzzy file switcher. Shift+Enter opens beside.
- Ctrl+Shift+F searches notes, code and PDF text; Ctrl+F searches the active file. Results highlight matches and reject stale offsets. A 1,000-file text vault scans in 75 ms; PDF-heavy vaults are not measured.
- Backlinks and unresolved links panel. Renames preview link updates, block affected unsaved notes and keep an interrupted-operation journal with Resume.
- Comparison dialog for external changes and saved versions with Keep mine, Use disk, Keep both and Restore version. Unavailable files keep their working copy.
- HTML and XHTML source with a sandboxed preview. Local CSS and images load; scripts, forms and network are disabled.
- Export a note as self-contained HTML or PDF with images, diagrams and bundled fonts, with a 100 MiB embedded-data limit. Replacing an export keeps a `.before-export` recovery copy.
- Drag zoomed images and videos to pan; double-click to fit again.
