# Folio Implementation Plan

> For agentic workers: use superpowers:executing-plans to implement task by task. User authorized implementation; leave all changes uncommitted.

**Goal:** Build the native Linux knowledge workspace in the supplied Folio specification.

**Architecture:** Electron main owns vault access, watching, history, trash and proposals. A sandboxed preload exposes a typed bridge to React. Documents remain ordinary files; renderer state cannot authorize arbitrary filesystem access.

**Tech Stack:** Electron 45, electron-vite, Vite+, React, TypeScript, Tailwind v4, CodeMirror, unified, Excalidraw, pdf.js.

**Spec:** ../../specs/folio.md

## Global Constraints

Offline document workflows. Bundled fonts. No Node in renderer. No silent overwrites. Every agent mutation requires acceptance. Recoverable deletion. Warm light/dark design with integrated tabs. No commits, pushes or installation over an existing app.

## Review Focus

Traversal and symlinks must not escape vault. Stale writes must preserve disk and editor. Existing create targets must never be overwritten. Trash restore must not replace another file. Invalid app state must not prevent launch.
